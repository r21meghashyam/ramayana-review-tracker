# Ramayana review tracker

A single-page dashboard summarizing early reviewer reactions to *Ramayana: Rise of a Legend*.

## Publish

The page is hosted with GitHub Pages from the `main` branch root. Open `index.html` locally or visit the Pages site after deployment finishes.

## Update

Edit `index.html`, then commit and push to `main`. GitHub Pages will publish the update automatically.

The dashboard links to its cited review sources and marks paraphrases separately from short excerpts.
